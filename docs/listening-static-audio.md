# Статические записи «Аудирование 2.0»

Каталог `listening-pilot-v1` содержит 60 оригинальных комплектов. Озвучка планируется по
ролям: один immutable MP3 на один сегмент сценария. Готовые файлы перечисляются в
`public/audio/listening/listening-pilot-v1/manifest.json`; до их появления интерфейс честно
показывает «Тренировочная синтезированная озвучка».

## Безопасный dry-run

Обычная команда только валидирует каталог и существующие файлы, перечисляет недостающие
пути и считает символы и стоимость. Она не вызывает `fetch`, не обращается к xAI и не пишет
MP3 или manifest:

```powershell
npm.cmd run listening:audio:dry-run
```

Для короткой сводки без списка из сотен путей:

```powershell
npm.cmd run listening:audio:dry-run -- --summary
```

Цена настраивается, текущая официальная ставка по умолчанию — 15 USD за миллион символов:

```powershell
npm.cmd run listening:audio:dry-run -- --summary --usd-per-million=15
```

Источник ставки: [xAI API pricing](https://docs.x.ai/developers/pricing). Перед фактическим
запуском ставку нужно заново сверить с официальной страницей.

## Отдельный финансовый gate

Реальная генерация не запускается одной случайной командой. Одновременно требуются:

1. режим `--paid` (его добавляет npm script);
2. точная фраза `--confirm-paid=I_ACCEPT_XAI_TTS_CHARGES`;
3. `XAI_API_KEY` только в окружении процесса.

```powershell
$env:XAI_API_KEY = '<ключ из xAI Console>'
npm.cmd run listening:audio:generate -- --confirm-paid=I_ACCEPT_XAI_TTS_CHARGES --summary
Remove-Item Env:XAI_API_KEY
```

Ключ не записывается в каталог, manifest или лог. Конвейер принимает только MP3 с MIME
`audio/mpeg`, проверяет размер, MP3-сигнатуру и SHA-256, публикует файл и manifest атомарно.
При повторном запуске валидные готовые сегменты пропускаются; повреждённый ответ провайдера
не появляется в публичном каталоге.

xAI TTS принимает для английского обязательный код `language: en`; отдельного кода `en-GB`
в актуальном списке провайдера нет. Конвейер явно запрашивает MP3 24 kHz / 128 kbps и использует
lowercase voice id. Перед подтверждением платной генерации владелец должен прослушать голоса в
xAI Playground и подтвердить британское произношение: код языка сам по себе акцент не гарантирует.
Актуальный контракт: [xAI Text to Speech](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech).

Замедленный режим `0.7×` намеренно использует помеченную assisted-озвучку. Статические
записи всегда проигрываются с нормальной скоростью, чтобы не искажать экзаменационную речь.
