# Ротация ключей

1. Создать новый ключ у провайдера, не отключая старый.
2. Обновить соответствующую переменную окружения на VPS (`JWT_SECRET`, `TELEGRAM_BOT_TOKEN`, `XAI_API_KEY`, `GROQ_API_KEY` или пароль БД).
3. Перезапустить только контейнер приложения и проверить `/health/live`, `/health/ready` и один безопасный запрос.
4. Для `JWT_SECRET` учитывать принудительный выход всех пользователей.
5. Для пароля PostgreSQL синхронно обновить роль БД и `DATABASE_URL`.
6. Отозвать старый ключ у провайдера после успешной проверки.
7. Запустить `npm run security:secrets` и проверить логи без вывода значения ключа.

Никогда не вставляйте секреты в issue, commit, CI log или этот документ.
