# Issue tracker

Этот репозиторий использует **локальный markdown-трекер**. Внешнего трекера нет: ни GitHub Issues,
ни GitLab, ни Linear. Причина — владелец проекта работает без командного аккаунта, а тикеты должны
переживать смерть диалога с агентом.

## Где живут задачи

```
.scratch/<feature-slug>/spec.md              спека фичи — единственная точка сверки
.scratch/<feature-slug>/issues/NN-slug.md    по одному файлу на тикет
PROGRESS.md                                   живая сводка по всем тикетам, в корне репозитория
```

`NN` нумеруется с `01` в порядке зависимостей: блокирующие тикеты идут первыми.
Тикет, существующий только в диалоге, тикетом не является.

## Шаблон тикета

```markdown
# NN — Короткое название

Status: ready-for-agent
Blocked by: —
Spec: .scratch/<feature-slug>/spec.md#<якорь-раздела>

## Что сделать

Одним абзацем: какое наблюдаемое поведение появится или изменится.

## Границы

- Что входит.
- Что явно не входит (чтобы агент не расширил задачу).

## Файлы

- `путь/к/файлу.js` — что там меняется.

## Definition of Done

- [ ] Проверяемый признак 1.
- [ ] `npm test` проходит.
- [ ] `npm run lint` и `npm run check` проходят.
- [ ] Один коммит на тикет.
```

## Статусы

| Статус | Значение |
|---|---|
| `needs-triage` | задача записана, границы не определены |
| `needs-info` | ждёт решения или данных от владельца |
| `ready-for-agent` | границы ясны, можно брать в работу |
| `ready-for-human` | требует действия владельца (доступы, секреты, живые устройства) |
| `in-progress` | взята в работу |
| `done` | выполнена, коммит есть |
| `failed` | две попытки не удались, нужен разбор |
| `wontfix` | решено не делать, причина записана в тикете |

## Правила

- Один тикет — один агент — один свежий контекст. Два тикета в одном контексте запрещены.
- Один тикет — один коммит. Коммиты и есть точки отката.
- Параллельно берутся только тикеты, не пересекающиеся по файлам.
- Статус в файле тикета и строка в `PROGRESS.md` обновляются сразу после завершения работы.
- Секреты в тикеты не попадают: только имена переменных окружения, никогда значения.
