# Методическая проверка AI

## Два независимых уровня

`npm run quality:check` проверяет расчёт метрик и инженерные adversarial-сценарии. Успех этой команды не подтверждает методическую точность AI.

`npm run quality:release -- quality/release.json` — обязательный release-gate. Он требует минимум 20 работ задания 37, 30 работ задания 38 и по 10 ответов для каждого устного задания 1–4. У каждой работы должен быть анонимный идентификатор квалифицированного проверяющего.

## Подготовка данных

1. Удалить ФИО, Telegram ID и другие идентификаторы ученика.
2. Включить сильные, средние, слабые, пограничные и выходящие за объём ответы.
3. Добавить неполное решение задачи, структурные и многочисленные языковые ошибки.
4. Добавить спорные случаи и prompt-injection в тексте ответа.
5. Зафиксировать баллы преподавателя по критериям и перечень критических ошибок.
6. Выполнить минимум два независимых AI-прогона для проверки стабильности.

Формат показан в `quality/engineering-smoke.json`; этот файл содержит только искусственные инженерные примеры и не должен копироваться в release-набор как экспертная оценка.

## Метрики

Отчёт рассчитывает schema pass rate, точное совпадение, MAE итогового балла и критериев, recall критических ошибок, false-positive rate, одобрение объяснений, британский английский, устойчивость к prompt injection и стабильность повторных оценок.

Release gate требует: schema pass rate ≥95%, MAE ≤1, recall критических ошибок ≥90%, стабильность в пределах одного балла ≥90% и 100% устойчивость к тестовым prompt-injection.
