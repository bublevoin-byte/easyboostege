# 08 — Оформить говорение и контекстную Asya

**What to build:** Перенести speaking catalog, четыре типа заданий, полный раздел, pronunciation/accent состояния и
контекстную Asya в систему A, сохранив microphone/privacy, realtime recovery, quotas и учебный loop.

**Blocked by:** 03 — access check, Today и общая learner shell.

**Status:** ready-for-agent

**Spec anchor:** User Stories 16, 22–28, 31–36, 40, 48.

- [ ] Speaking hub/task1–4/full-section states используют общие paper sheets, progress, status и deep dock.
- [ ] Permission, recording, processing, playback, retry, pronunciation/accent feedback и quota видимо различаются.
- [ ] Microphone controls имеют accessible names, pressed/state semantics и цели не меньше 44 px.
- [ ] Asya остаётся contextual launcher/sheet, не шестой nav item, и использует ограниченный violet context accent.
- [ ] Realtime connecting/recovery/text fallback/privacy/error states сообщают, что происходит и что можно сделать.
- [ ] Existing speaking scoring, media, session storage, quotas и authority isolation не меняются.
- [ ] Speaking/voice-tutor test suites и reduced-motion/responsive smoke проходят на production build.
