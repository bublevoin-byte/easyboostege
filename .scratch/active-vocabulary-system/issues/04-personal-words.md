# 04 — Личные слова из чтения без противоречий

Status: done
Blocked by: 01 — Освоение слова и мягкая миграция; 02 — Библиотека, темы и подробная карточка
Spec: `.scratch/active-vocabulary-system/spec.md#user-stories`

## Что сделать

Добавление из Reading создаёт настоящую личную карточку с устойчивой идентичностью, исходным предложением и явным provenance, а действия «Учить» и «Знаю» одинаково отражаются в библиотеке и расписании Words.

## Границы

- Входит: нормализация, сохранение контекста, personal provenance, совместимые действия learn/known, поиск и удаление/сброс только личной карточки с подтверждением.
- Не входит: автоматическое повышение личного слова до проверенной базы ЕГЭ.

## Definition of Done

- [x] «Учить» создаёт доступную карточку и не объявляет неизвестную часть речи существительным.
- [x] «Знаю» влияет на состояние Words, но остаётся слабым self-reported сигналом.
- [x] Повторное добавление не создаёт дубль и сохраняет полезный контекст.
- [x] Личные слова не увеличивают verified EGE coverage.
- [x] `npm run lint`, `npm run check` и целевые тесты проходят.
- [x] Один коммит на тикет.
