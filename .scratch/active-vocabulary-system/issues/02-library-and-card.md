Status: done

## Что сделать

Экран «Слова» становится понятной домашней страницей с сегодняшним объёмом, поиском, тематическими и статусными фильтрами, постоянным списком всех начатых слов и доступной подробной карточкой с контекстом и озвучкой.

## Границы

- Входит: главная Words, библиотека, много-теговая тема, фильтры, provenance, карточка, скрываемые переводы примеров, аудио и состояния пусто/загрузка/ошибка.
- Не входит: финальный смешанный тренажёр и адаптивная запись результата.

## Definition of Done

- [x] Ученик видит due/new/time до старта и может выбрать 5/10/15/20 новых слов.
- [x] Все начатые слова доступны сразу; фильтры и поиск сохраняются при возврате.
- [x] Карточка не изменяет mastery и не выдумывает отсутствующие метаданные.
- [x] Core и personal/generated визуально и семантически различаются.
- [x] Клавиатура, screen reader, 375px и reduced motion покрыты тестами.
- [x] `npm run lint`, `npm run check` и целевые тесты проходят.
- [x] Один коммит на тикет.
