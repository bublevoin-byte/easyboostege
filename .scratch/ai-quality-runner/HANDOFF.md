## Что открыто — по убыванию важности

**1. Записи `aiRuns` не несут версию промпта.** Слияние различает прогоны парой «провайдер +
модель», поэтому в наборе `grok-4.5` — это замер на `writing-v4`, а `grok-4.3` — на `writing-v3`, и
по самому набору этого не узнать. Новый замер той же модели **затирает** прежний. Версию помнят
журналы `quality/runs/*.jsonl`, но они в `.gitignore` и существуют только на машине владельца.
Пока это не починено, любая цифра из `quality:check` — цифра неизвестного происхождения.

**2. `XAI_MODEL` в `.env`.** По умолчанию в `config.js` и `.env.example` стоит `grok-4.5`, которая
отвечает **118 секунд** при бюджете операции `writing_37` в 45 секунд. Если она стоит на сервере,
ученики получают ошибку вместо разбора. На машине владельца проверено, на VPS — нет. `grok-4.3`
отвечает за 10,6 секунды и в бюджет укладывается.

**3. Объём эталонного набора.** §11.1 требует 20 работ задания 37 и 30 задания 38; есть 12 и 9.
Устные задания 1, 2 и 4 — по 10, есть 0; задание 3 перекрыто (14). Это главный рычаг: на 21 работе
один ложный ноль двигает общую метрику на 12%, то есть мерится не столько модель, сколько случай.
Пути пополнения разобраны в `quality/SOURCES.md`; методичка ФИПИ за 2022 год не разбиралась вовсе,
а формат заданий с 2022 года не менялся.

**4. Три метрики §11.2 не измерены ни разу** — корректность объяснений, британский английский,
устойчивость к prompt injection. Их ставит человек по опроснику `quality:worksheet-review`.
Преподавателей в проекте нет; владелец судит сам. В отчёте они честно показаны как `null`, а не
как ноль, — это сделано тикетом 04 и ослаблять нельзя.

**5. Полнота обнаружения критических ошибок не измеряется ничем**: `expectedCriticalErrors` пуст у
всех работ, таксономии кодов нет. Разбор ИИ возвращает ошибки текстом. Полные тексты лежат в
журналах, так что коды можно вывести задним числом без нового прогона.

**6. Дневной бюджет ИИ общий на всех.** `hasAiBudget()` в `middleware/subscription.js` считает
`AI_DAILY_REQUEST_BUDGET` без фильтра по пользователю: один активный ученик может выесть общий
дневной лимит, остальные получат `503 AI_BUDGET_EXHAUSTED`. Решение владельца 31 июля: лимит
станет персональным и будет зависеть от уровня подписки. Не сделано.

**7. Прогон устной части** не написан — раннер сделан только для письменной.

## Правила, которые нельзя нарушать

- **Push в `production-hardening` разворачивает staging** и сбрасывает отсчёт семидневного soak.
  Отправлять только по слову владельца. Сейчас не отправлено 35 коммитов — осознанно.
- **Платные прогоны, деплой, установка пакетов — действия владельца.** Агент их не начинает сам.
  Один вызов `grok-4.5` стоит около трёх с половиной центов, `grok-4.3` — около полуцента.
- **Ни один тест не удаляется и не ослабляется** ради зелёной сборки. Порог двигается только
  вместе с записанной причиной.
- **Секреты**: только имена переменных окружения (`XAI_API_KEY`, `GROQ_API_KEY`), никогда значения.
  `.env` в `.gitignore`. `.env.example` — в git, ключам там не место.
- **Ничего не выдумывать в эталонном наборе**: ни работ, ни баллов, ни процентов, ни методики.
  Всё, что попадает в промпт как правило ФИПИ, обязано иметь цитату в методичке.
- Перед коммитом: `npm run lint`, `npm run check`, `npm test`.
- Сообщения коммитов **английские**, тема и тело.

## Главный урок этой работы

Почти все находки — про одно: **тихая подмена «не измерено» на «не пройдено» или наоборот**.
Пустое поле суждения считалось провалом. Гейт проходил при полном отсутствии данных, потому что

закреплены на проходящем состоянии и покраснели бы ровно тогда, когда владелец сделает то, о чём

Каждый раз цифра существовала и выглядела убедительно. Проверяйте не наличие числа, а его
происхождение.

## Ловушки этой машины, проверенные на своей шкуре

- **Путь содержит кириллицу и пробел.** Git запускать как
  `git -C "C:/Users/Ригер/Desktop/Repetotor/Приложение репетитор/server" ...`, не через `cd`.
- **Многострочные here-string в PowerShell ломаются.** Сообщение коммита писать в файл во
  временном каталоге и делать `git commit -F <файл>`.
- **`!!` в bash — подстановка из истории**, срабатывает даже внутри двойных кавычек и молча
  подменяет команду.
- **`Select-Object -First N` рвёт конвейер**, и node падает с ненулевым кодом на ровном месте.
- **`npm run <script> args` без `--` не передаёт аргументы.**
- **`quality/sources/` в `.gitignore`**: PDF есть на машине владельца, на свежем клоне их нет.
  Текст извлекается только `pdftotext -enc UTF-8 -layout`, без `-enc` кириллица теряется.
- **Playwright использует системный Chrome**, встроенный headless shell не установлен.
- **`/tmp` в Git Bash и в node — разные каталоги.**

## Как воспроизвести числа

```
npm run quality:check -- quality/writing-fipi-stubs.json --model=grok-4.5
```

Без `--model` отчёт громко предупредит, что смешивает прогоны разных моделей, и будет прав.

Полный прогон заново — только с ключами провайдера в `.env` и только по решению владельца:

```
npm run quality:run -- --provider=grok --model=grok-4.3 --runs=2
npm run quality:merge-runs -- quality/runs/<имя, которое напечатает команда>
```

Готовность по ТЗ: `npm run tz:readiness -- "<путь к ТЗ>"`. **Пункты раздела 11 в ТЗ не размечены
и размечаться не должны, пока метрики не взяты**: инструмент их не закрывает, закрывают цифры.
