# 06 — Слияние журнала прогона в эталонный набор

Status: ready-for-agent
Blocked by: 05
Spec: .scratch/ai-quality-runner/spec.md#слияние-scriptsmerge-quality-runsjs

## Что сделать

Журнал прогона сворачивается в поля `aiRuns` набора — ту форму, которую читает `ai/quality.js`.
Отдельным шагом от самого прогона: платный журнал не должен теряться из-за ошибки при записи
набора, а изменение эталонного файла должно быть видно в diff.

```bash
npm run quality:merge-runs -- quality/runs/<метка>.jsonl
```

## Границы

Входит:

- Скрипт `scripts/merge-quality-runs.js`.
- Сопоставление ключей критериев. ИИ возвращает критерии русскими названиями, набор хранит
  `human.criteria` ключами `k1`…`k5` и расшифровку в `human.criteriaLabels`. Слияние сопоставляет
  по названию и **падает при несовпадении**, называя работу и критерий. Тихий сдвиг ключа испортил
  бы отклонение по критериям незаметно: `ai/quality.js` сличает критерии по имени.
- Форма записи — как в `quality/engineering-smoke.json`: `valid`, `total`, `criteria`,
  `detectedErrors`, `explanationApproved`, `britishEnglishApproved`, `injectionResisted`. Плюс
  `repaired`, `provider`, `model` — их пишет раннер, и они нужны, чтобы прогоны разных провайдеров
  нельзя было спутать.
- Три поля человеческого суждения записываются как `null` — «не измерено». Их заполняет тикет 07.
- `detectedErrors` записывается пустым списком: разбор ИИ возвращает ошибки текстом, а не кодами,
  таксономии критических ошибок в проекте нет, и `expectedCriticalErrors` пуст у всех 21 работы.
- Повторное слияние того же журнала не удваивает `aiRuns`.
- Пять работ с тегом `total-only` (у них есть общий балл, но нет разбивки по критериям) сливаются
  без поля `criteria` и не роняют скрипт.
- Новый файл добавляется в список `npm run check`.

Не входит:

- Подстановка `true` в поля человеческого суждения. Прямой запрет из HANDOFF: это превращает
  проверку в самообман.
- Выведение кодов критических ошибок из текста разбора. Полный текст лежит в журнале, вывести коды
  задним числом можно будет без нового прогона — но это отдельная работа с явной таксономией.
- Правка `human`, `answer`, `source` — эталон не трогается.

## Файлы

- `scripts/merge-quality-runs.js` — новый: слияние.
- `package.json` — команда `quality:merge-runs`, новый файл в `check`.
- `test/quality-merge-runs.test.js` — новый: сопоставление критериев по названию; падение при
  несовпадении; повторное слияние не удваивает; работа `total-only` сливается без критериев;
  три поля суждения равны `null`.

## Definition of Done

      жалобу на пустой `aiRuns`.
- [ ] Несовпадение названия критерия роняет слияние с указанием работы и критерия.
- [ ] Повторный запуск на том же журнале не меняет набор.
- [ ] `npm test` проходит.
- [ ] `npm run lint` и `npm run check` проходят.
- [ ] Один коммит на тикет.
