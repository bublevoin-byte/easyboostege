# 01 — Вынести цепочку вызова провайдера в общий модуль

Status: done
Blocked by: —

## Что сделать

Цепочка, которой приложение зовёт ИИ — вызов провайдера, подмена на запасного, одна попытка
восстановления формата — переезжает из замыкания `createAiRoutes()` в отдельный модуль
`ai/provider-client.js`. Наблюдаемое поведение приложения не меняется ни на йоту: те же запросы,
те же ошибки, те же коды. Меняется только то, что теперь эту цепочку может позвать не один лишь
веб-сервер, но и скрипт из командной строки — без чего раннер проверял бы копию логики вместо
самого приложения.

## Границы

Входит:

- Новый модуль `ai/provider-client.js` с фабрикой, отдающей `askProvider`, `aiProviders`,
  `askWithFallback`, `parseWithOneRepair` и `limitsFor`.
- `routes/ai.js` импортирует их вместо своих определений.
- Ворота конкурентности (`createConcurrencyGate`) создаются внутри модуля, один экземпляр на процесс
  — сегодня это модульная переменная `gate` в `routes/ai.js`, и её поведение сохраняется.
- Возможность выбрать одного провайдера и запретить подмену — раннеру это нужно, приложению нет.
  Достаточно необязательного параметра фабрики; штатный путь остаётся штатным.
- Новый файл добавляется в список `npm run check` в `package.json`.
- Перенацеливание одного теста на новый файл. `test/ai-operations.test.js` проверяет клампы и вызов
  провайдера по тексту файла, а не по поведению: он читает `routes/ai.js` и ищет в нём выражения,
  которые вместе с цепочкой переезжают в `ai/provider-client.js`. Меняется только путь в
  `fs.readFile` — ассерты, название теста и порог остаются дословно.

Не входит:

- Любая правка поведения: таймауты, температура, порядок провайдеров, тексты ошибок, логирование
  в `ai_requests`, метрики зависимостей — всё остаётся как есть.
- Речевые и генерирующие операции не переписываются: они уже зовут те же функции и просто
  начинают брать их из модуля.
- Ослабление тестов. Если краснеет тест на поведение — значит поведение поехало, и чинится код,
  а не тест. Разрешена ровно одна правка выше, и она не трогает ни одного ассерта.

## Файлы

- `ai/provider-client.js` — новый: цепочка вызова провайдера.
- `routes/ai.js` — удаление перенесённых определений, импорт из модуля.
- `package.json` — новый файл в `npm run check`.
- `test/provider-client.test.js` — новый: вызов на подставном провайдере, подмена на запасного,
  запрет подмены при закреплённом провайдере, одна попытка восстановления формата.
- `test/ai-operations.test.js` — путь в `fs.readFile` переводится на новый файл, ассерты те же.
