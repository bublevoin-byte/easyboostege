# 03 — Опросник по трём диаграммам и слияние данных

Status: done
Blocked by: 02

## Что сделать

Три работы задания 38 построены на круговой диаграмме: цифры там картинкой, в текстовом слое PDF
их нет, и ни один разбор источника их не достанет. Появляется опросник — файл, где по каждой из
трёх работ указана методичка, страница и пустая таблица «подпись — процент». Владелец переносит
цифры с диаграммы один раз, скрипт вливает их в набор с проверкой. После этого все 9 работ задания
38 идут в прогон.

Работы: `w38-fipi-2023-006`, `w38-fipi-2026-3896`, `w38-fipi-2026-3468`.

## Границы

Входит:

- Скрипт `scripts/build-pie-chart-worksheet.js` (`npm run quality:charts`), собирающий
  `quality/pie-chart-worksheet.md` из работ с тегом `assignment-partial`.
- В опроснике по каждой работе: идентификатор, тема проекта из условия, `source.manual`,
  `source.assignmentPage`, и таблица-заготовка на 3–8 строк.
- Скрипт `scripts/merge-pie-charts.js` (`npm run quality:merge-charts`), читающий заполненный
  опросник обратно в `assignmentData` и снимающий тег `assignment-partial` у заполненных работ.
- Проверки при слиянии: 3–8 строк, процент целый в диапазоне 0–100, подпись непустая, результат
  проходит `writingAssignmentSchema`. Не сошлось — падение с указанием работы, а не тихая запись.
- Незаполненная работа пропускается без ошибки: опросник можно сдавать по частям.
- Новые файлы добавляются в список `npm run check`.

Не входит:

- Распознавание диаграмм из PDF. Пробовали, данных в тексте нет.
- Любое додумывание процентов за владельца.
- Требование, чтобы проценты давали в сумме 100: у ФИПИ встречаются диаграммы с несколькими
  вариантами ответа, и жёсткая сумма отвергла бы верные данные.

## Файлы

- `scripts/build-pie-chart-worksheet.js` — новый: сборка опросника.
- `scripts/merge-pie-charts.js` — новый: слияние в набор.
- `quality/pie-chart-worksheet.md` — новый: опросник, пустой на момент коммита.
- `package.json` — команды `quality:charts` и `quality:merge-charts`, новые файлы в `check`.
- `test/quality-pie-charts.test.js` — новый: разбор заполненного опросника, отказ на проценте вне
  диапазона, пропуск незаполненной работы.

## Definition of Done

      `assignment-partial` и оставляет незаполненные работы нетронутыми.
- [ ] Процент вне 0–100 или меньше трёх строк роняют слияние с внятным сообщением.
- [ ] `npm test` проходит.
- [ ] `npm run lint` и `npm run check` проходят.
