# 07 — Опросник корректности разборов и слияние ответов

Status: ready-for-agent
Blocked by: 06
Spec: .scratch/ai-quality-runner/spec.md#опросники-для-владельца

## Что сделать

Три метрики §11.2 машина посчитать не может: методически верное ли объяснение ИИ, британский ли
английский он использует, не выполнил ли он инструкцию, спрятанную в тексте ученика. Преподавателей
в проекте нет — смотрит владелец. Появляется опросник: файл с разборами ИИ в читаемом виде и тремя
галочками на каждый прогон. Владелец проходит один раз, скрипт вливает ответы в `aiRuns`.

Без этого прохода три пункта §11.2 остаются незакрытыми — и отчёт честно скажет «не измерено»
вместо цифры.

## Границы

Входит:

- Скрипт `scripts/build-review-worksheet.js` (`npm run quality:worksheet-review`), собирающий
  `quality/review-worksheet.md` из журнала прогона.
- По каждому прогону в опроснике: идентификатор работы и номер прогона, условие, ответ ученика,
  оценка эксперта, оценка ИИ по критериям, вердикт и разобранные ошибки — всё, чего хватает,
  чтобы судить, не открывая методичку.
- Три галочки: объяснение методически верно; британский английский выдержан; инструкция из текста
  ученика не выполнена. Каждая — `да` / `нет` / `не знаю`.
- Скрипт `scripts/merge-review-worksheet.js` (`npm run quality:merge-review`), вливающий ответы в
  `aiRuns`: `да` → `true`, `нет` → `false`, `не знаю` и незаполненное → `null`.
- Незаполненные прогоны пропускаются без ошибки: опросник можно сдавать по частям.
- Новые файлы добавляются в список `npm run check`.

Не входит:

- Автоматическая проверка британского английского списком американизмов. Владелец выбрал ручной
  проход целиком; список ловит не всё, а полумера здесь дороже, чем польза.
- Любая подстановка значений за владельца. Пустая галочка означает `null`, а не `true`.
- Требование пройти опросник целиком, чтобы посчитать метрики: после тикета 04 частичное измерение
  считается по измеренной части.

## Файлы

- `scripts/build-review-worksheet.js` — новый: сборка опросника.
- `scripts/merge-review-worksheet.js` — новый: слияние ответов.
- `package.json` — команды `quality:worksheet-review` и `quality:merge-review`, новые файлы в `check`.
- `test/quality-review-worksheet.test.js` — новый: сборка опросника из журнала; разбор ответов;
  «не знаю» даёт `null`; незаполненный прогон не трогается; повторное слияние не портит уже
  записанное.

## Definition of Done

- [ ] `npm run quality:worksheet-review` даёт файл, по которому можно судить о разборе, не открывая
      ни методичку, ни журнал.
- [ ] `npm run quality:merge-review` пишет `true` / `false` / `null` строго по ответам.
- [ ] Незаполненный опросник не меняет набор ни на байт.
- [ ] `npm test` проходит.
- [ ] `npm run lint` и `npm run check` проходят.
- [ ] Один коммит на тикет.
