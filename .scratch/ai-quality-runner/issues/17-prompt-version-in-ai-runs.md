# 17 — Версия промпта сохраняется в `aiRuns`

Status: done
Blocked by: 14

## Что сделать

Слияние переносит `promptVersion` из каждой измеренной строки журнала в `aiRuns` и различает
замеры по тройке «провайдер + модель + версия промпта». Новый замер той же модели на новом
промпте не затирает прежний, а отчёт не может молча назвать смесь версий измерением одной версии.

## Границы

Входит:

- Происхождение каждого ответа в `aiRuns`: `provider`, `model`, `promptVersion`.
- Идентичность замера по тройке «провайдер + модель + версия промпта» при слиянии журнала и
  человеческой проверки.
- Выбор версии промпта в отчёте и громкое предупреждение, если после остальных фильтров смешаны
  несколько версий.
- Совместимость старых записей без `promptVersion`: они называются неизвестной версией, а не
  приписываются текущей.

Не входит:

- Изменение промпта, формул метрик и порогов §11.3.
- Перезапись сырых журналов и выдумывание версии для уже слитых записей.
- Платный прогон ИИ.
