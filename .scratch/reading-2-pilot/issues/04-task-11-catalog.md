# 04 — Создать 20 комплектов задания 11

Status: ready-for-agent
Blocked by: 02
Spec: `.scratch/reading-2-pilot/spec.md#задание-11`

## Что сделать

Создать оригинальный статический каталог из 20 комплектов задания 11 официального размера: связный текст, 6 пропусков, 7 фрагментов, один лишний, уникальные ключи, проверяемый контекст и объяснение связи. Распределение уровней 4 B1 / 12 B2 / 4 B2+/C1.

## Границы

- Входит автоматическая сборка восстановленного текста и проверки структурной целостности.
- Не входит копирование или перефразирование конкретных материалов ФИПИ/издательств.
- Не входят задания 10 и 12–18 и изменение экрана.

## Файлы

- отдельный catalog shard в `public/content/reading/`
- контрактные тесты контента задания 11

## Definition of Done

- [ ] Ровно 20 валидных оригинальных комплектов и распределение 4/12/4.
- [ ] Правильные подстановки дают связный текст; один фрагмент действительно лишний.
- [ ] Каждый ключ имеет проверяемый контекст и содержательное русское объяснение.
- [ ] Каталог проходит общий строгий валидатор Reading.
- [ ] Целевые тесты, `npm run lint`, `npm run check`, `npm test` проходят.
- [ ] Один коммит на тикет.
