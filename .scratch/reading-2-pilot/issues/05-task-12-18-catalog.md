# 05 — Создать 20 комплектов заданий 12–18

Status: ready-for-agent
Blocked by: 02
Spec: `.scratch/reading-2-pilot/spec.md#задания-12–18`

## Что сделать

Создать оригинальный статический каталог из 20 длинных текстов, у каждого 7 вопросов, 4 варианта, один ключ, точная цитата-доказательство и объяснение. Распределение уровней 4 B1 / 12 B2 / 4 B2+/C1.

## Границы

- Входит разнообразие жанров/тем и проверка того, что доказательство является подстрокой текста.
- Не входит копирование или перефразирование конкретных материалов ФИПИ/издательств.
- Не входят задания 10 и 11 и изменение экрана.

## Файлы

- отдельный catalog shard в `public/content/reading/`
- контрактные тесты контента 12–18

## Definition of Done

- [ ] Ровно 20 валидных оригинальных комплектов и распределение 4/12/4.
- [ ] В каждом комплекте ровно 7 вопросов по 4 варианта с одним ключом.
- [ ] Все 140 доказательств являются точными цитатами исходного текста.
- [ ] Каталог проходит общий строгий валидатор Reading.
- [ ] Целевые тесты, `npm run lint`, `npm run check`, `npm test` проходят.
- [ ] Один коммит на тикет.
