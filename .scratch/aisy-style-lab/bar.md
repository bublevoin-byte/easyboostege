# Визуальная планка Aisy Style Lab

1. **Только телефон:** learner-canvas имеет ширину не больше `390px`; обязательные рендеры — `390×844` и `360×720`. На широком окне тот же canvas только центрируется: top-level Today/Progress сохраняют пять разделов снизу, deep task/review — нижний action-dock; бокового rail нет.
2. **Одна общая марка:** на каждом экране используются warm-paper фон, plum/ink текст и не более одного кораллового primary CTA. До первого скролла одновременно видно не больше двух дополнительных цветовых акцентов; A/B/C не превращаются в три разные палитры.
3. **Три типографические роли:** выразительный заголовок Nunito `30–34px`, основной Acrom `15–16px`, label/eyebrow Acrom `11–13px`. На одном экране нет четвёртого размера основной иерархии; обычный текст имеет контраст не ниже `4.5:1`.
4. **Иерархия поверхности читается по глубине:** максимум три уровня `фон → hero/sheet → control`; hero визуально крупнее любой вспомогательной карточки минимум в `1.6×`. Тени направлены вниз-вправо, вложенный control имеет меньший радиус и меньшую тень, а равноправной сетки из одинаковых карточек на Today нет.
5. **Первый экран отвечает без поиска:** Today показывает рекомендацию, длительность и одну кнопку start/continue; task показывает вопрос и варианты; review показывает вердикт и правило; Progress показывает изменение и следующий шаг. Все активные цели не меньше `44×44px`, primary CTA и bottom-nav не перекрывают safe area.
6. **Движение имеет один вектор и один главный эффект:** press длится `160–220ms`, переход экрана `320–520ms`; A сдвигает бумажные слои, B вдавливает/освобождает физический control, C рисует маршрут вперёд. На одном переходе работает только одна signature-анимация; reduced-motion убирает пространственное движение и оставляет смену состояния через opacity.
7. **Сравнение честное и кликабельное:** A/B/C используют один текст, числа, ответ и порядок `Сегодня → задание → разбор → прогресс`, одинаковые пять top-level destinations и одинаковый deep action-dock. Любой из четырёх экранов открывается по URL и после reload остаётся тем же экраном; различается только композиция, поверхность и signature-motion.
