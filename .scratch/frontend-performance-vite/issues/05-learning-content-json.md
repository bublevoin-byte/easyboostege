# 05 — Вынести учебный контент из кода в загружаемые данные

Status: ready-for-agent
Blocked by: 03
Spec: .scratch/frontend-performance-vite/spec.md#43-учебный-контент

## Что сделать

Закрыть требование раздела 19 «первый экран не зависит от загрузки всего учебного контента».
Сейчас словари, тексты для чтения, наборы вопросов грамматики, диалоги аудирования и банк тем
письма лежат прямо в коде и приезжают при старте приложения, даже если ученик открыл только
главный экран.

Перенести их в JSON рядом с `public/task-bank.json` и загружать вместе с чанком своего экрана.

## Границы

**Входит:**

- Учебные данные из `public/app.js` и модулей — в файлы JSON в `public/content/`.
- Модуль экрана загружает свои данные при первом открытии и кэширует в памяти.
- `public/service-worker.js`: файлы контента кэшируются так же, как чанки экранов, чтобы офлайн
  работали встроенные задания — требование раздела 6.1.
- Проверка целостности в `scripts/build-frontend.js` распространяется на новые файлы.

**Не входит:**

- Изменение самого учебного содержания: тексты, вопросы и ответы переносятся дословно.
- Перенос банка заданий с сервера — он уже общий и живёт в базе (раздел 10.1).
- Генерация нового контента.

## Файлы

- `public/content/*.json` — новые
- `public/app.js`, `public/screens/*.js`
- `public/service-worker.js`
- `scripts/build-frontend.js`
- `test/*.test.js` — тесты, утверждающие что-то про содержание заданий
