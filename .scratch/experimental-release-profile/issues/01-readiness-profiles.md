Status: done

## Что сделать

Добавить в `scripts/tz-readiness.js` два воспроизводимых профиля, тесты публичного CLI и разметить внешний ТЗ так, чтобы строгие методические требования оставались открытыми, а экспериментальный запуск имел собственный честный знаменатель.

## Границы

- Входит: CLI `--profile`, метаданные Markdown, автоматические тесты, описание методики в ТЗ, начальные строгий и экспериментальный расчёты.
- Не входит: признание критериев §24 выполненными без аудита, изменение продукта, платные вызовы, push и deploy.

## Definition of Done

- [x] Профиль по умолчанию `strict` воспроизводит исходные 436/477 и 41 открытый пункт до аудита.
- [x] `--profile experimental` исключает ровно 28 пунктов §11 и критерий 12 §24, не помечая их выполненными.
- [x] Вывод явно сообщает профиль и количество исключений; `--open` их не маскирует под выполненные.
- [x] Метка профильного выполнения поддержана, но критерий 1 §24 ещё не засчитан до тикета 02.
- [x] Ошибочные аргументы дают понятную ненулевую ошибку.
- [x] Добавлены тесты публичного CLI; `npm run lint`, `npm run check` и `npm test` проходят.
- [x] Внешний ТЗ объясняет оба профиля и команды воспроизведения.
- [x] Проведён двухосевой review относительно исходного коммита; замечания устранены или обоснованы.
- [x] Один локальный коммит на тикет; несвязанные изменения не затронуты.

## Результат

CLI получил строгий профиль по умолчанию и профиль `experimental`, метаданные исключения/профильного
выполнения и явную проверку аргументов. Публичные CLI-тесты прошли 4/4; полный набор — 410 пройдено,
1 PostgreSQL-тест пропущен штатно. Строгий расчёт остался 436/477 с 41 открытым пунктом, а
экспериментальный составляет 436/448 с 12 открытыми и 29 явно исключёнными требованиями. Критерий
§24.1 не засчитан. Standards-review и spec-review замечаний больше не имеют.
