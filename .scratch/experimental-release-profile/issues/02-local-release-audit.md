# 02 — Провести локальный аудит экспериментального релиза

Status: done
Blocked by: 01
Spec: .scratch/experimental-release-profile/spec.md#testing-decisions

## Что сделать

На зафиксированном кандидате выполнить все доступные бесплатные локальные проверки, составить отчёт с доказательствами и обновить §24 и оба процента ТЗ только там, где критерий действительно подтверждён.

## Границы

- Входит: lint/check/tests, доступные browser E2E и performance, security scans, quality-runner, анализ известных дефектов, схем ИИ-ответов и релизных критериев, отчёт `docs/EXPERIMENTAL_RELEASE_AUDIT.md`.
- Не входит: сеть и платные ИИ-вызовы, установка отсутствующих компонентов, push/deploy, staging soak, физические устройства, секреты, внешние оповещения, юридическая проверка и второй сервер.

## Definition of Done

- [x] Отчёт фиксирует дату, исходный commit, все команды и точные результаты без секретных значений.
- [x] Обязательные локальные тесты, lint и check проходят; недоступные проверки честно записаны как ограничения.
- [x] Отдельно подтверждено или опровергнуто отсутствие известных critical/high дефектов.
- [x] Отдельно подтверждено или опровергнуто применение строгой схемы ко всем ИИ-операциям.
- [x] Критерии §24 меняются только на основании записанного доказательства.
- [x] Критерий 1 при наличии доказательств засчитывается только для экспериментального профиля, не для строгого.
- [x] Критерий 12 и §11 остаются явно открытыми в строгом профиле и исключёнными, а не выполненными, в экспериментальном.
- [x] Новый staging soak не объявлен начатым до разрешённого деплоя текущего кандидата.
- [x] Итоговые строгий и экспериментальный расчёты воспроизводятся командами readiness CLI.
- [x] Проведён двухосевой review относительно коммита тикета 01; замечания устранены или обоснованы.
- [x] Один локальный коммит на тикет; рабочее дерево чистое.

## Результат

Создан `docs/EXPERIMENTAL_RELEASE_AUDIT.md`. Локальный кандидат прошёл lint/check, 410 из 411
тестов при одном штатном skip, четыре browser E2E-профиля, performance, frontend build и два
secret scan. Целевые тесты строгих ИИ-схем прошли 44/44. `npm audit` не получил ответ от npm
registry и записан ограничением без расширения сетевых прав. Общим закрыт только §24.2. Из-за
штатного PostgreSQL skip §24.4 оставлен открытым; целевые schema-тесты подтверждают
content/writing/speaking, но не provider-ответы STT/TTS, поэтому §24.10 и §24.1 также открыты.
Staging, физические устройства, установка PWA, внешние alerts и полное восстановление на втором
сервере не закрыты. Двухосевой review: Standards — 0 замечаний; Spec — 3 замечания, все устранены.
