# 03 — Ввести строгие контракты ответов STT/TTS-провайдеров

Status: done
Blocked by: —

## Что сделать

Публичные `/api/v1/stt` и `/api/v1/tts` должны принимать только ответы внешних провайдеров, прошедшие строгий server-owned контракт, и сохранять действующие типизированные ошибки и fallback без выдачи malformed данных за успех.

## Границы

- Входит: строгие контракты STT JSON и TTS HTTP/audio, безопасные границы полей и размера, положительные и отрицательные тесты публичного поведения, обновление реестра ИИ-операций и связанной документации.
- Не входит: платные вызовы, смена провайдера, изменение публичных успешных форматов, методическая валидация §11, push/deploy.

## Definition of Done

- [x] STT отклоняет malformed JSON, пустой/неверный текст, неконечную, отрицательную или выходящую за границу duration и не возвращает частичный успех.
- [x] TTS отклоняет пустой, слишком большой или неподходящий по `Content-Type` ответ и не кэширует его как аудио.
- [x] Действующие публичные коды ошибок и fallback остаются совместимыми.
- [x] Положительные и отрицательные тесты написаны через согласованные публичные швы и проходят.
- [x] `docs/AI_OPERATIONS.md` точно описывает оба provider-контракта и границы доказательства §24.10.
- [x] `npm run lint`, `npm run check` и полный `npm test` проходят.
- [x] Проведён двухосевой review относительно исходного коммита тикета; замечания устранены или обоснованы.
- [x] Один локальный коммит на тикет.

## Результат

- STT принимает только `application/json` до 64 KiB с ровно полями `text` и `duration`: текст после нормализации — 1–10 000 символов, duration — конечное число 0–300 секунд.
- TTS primary принимает только `audio/mpeg` размером 1 byte–5 MiB; обе границы проверяются до кэширования, а Edge fallback проходит ту же проверку буфера.
- Публичные `STT_PROVIDER_UNAVAILABLE`, `STT_UNAVAILABLE`, `TTS_UNAVAILABLE` и Edge fallback сохранены; §24.10 оставлен итоговому аудиту тикета 05.
- Проверки: media contracts 14/14; lint и check — пройдены; полный `npm test` — 425 тестов, 424 пройдены, 1 штатно пропущен (PostgreSQL — scope тикета 04).
