# 03 — Сохранять происхождение каждого прогона

Status: done
Blocked by: 02 — Закрепить объективный ноль на сервере
Spec: .scratch/experimental-ai-assessment/spec.md#implementation-decisions

## Что сделать

Каждая письменная и устная попытка остаётся отдельной пользовательской записью вне золотого
набора и сохраняет полный набор данных для будущего анализа, включая провайдера, модель и версию
промпта; экспорт и удаление аккаунта продолжают охватывать эти записи.

## Границы

- Добавить модель к существующим письменным и устным попыткам в файловом и PostgreSQL-хранилищах.
- Сохранять известное происхождение успешных и неудачных прогонов и включать его в экспорт.
- Сохранить действующее каскадное удаление попыток вместе с аккаунтом.
- Уточнить схему, жизненный цикл данных, политику приватности и отделение журнала от золотого набора.
- Не создавать исследовательскую выгрузку, автоматический импорт пользовательских ответов в
  `quality/`, платный прогон, push или деплой.

## Файлы

- `migrations/019_attempt_models.sql` — nullable-модель для прежних и новых попыток.
- `storage/file-repository.js`, `storage/postgres-repository.js` — одинаковое хранение, экспорт и удаление.
- `routes/ai.js` — передача фактически известной модели в запись попытки.
- `docs/`, `public/privacy.html` — схема, retention, качество и privacy-границы.
- `test/` — маршрутные, репозиторные, миграционные и документационные регрессии.

## Definition of Done

- [x] Завершённая письменная и устная попытка сохраняет модель рядом с уже существующими провайдером и версией промпта.
- [x] Неудачная попытка по-прежнему сохраняется с входом, происхождением, статусом и кодом ошибки настолько полно, насколько данные известны.
- [x] Файловое и PostgreSQL-хранилища реализуют одинаковый контракт.
- [x] Экспорт пользователя включает происхождение попыток, а удаление аккаунта удаляет сами попытки как и раньше.
- [x] Документация называет попытки журналом пользовательских прогонов, отделяет его от золотого набора и запрещает автоматический импорт в эталон.
- [x] Документация объясняет, что будущий исследовательский экспорт требует псевдонимизации и очистки свободного текста от персональных данных.
- [x] Миграция совместима с уже существующими попытками.
- [x] Репозиторные и маршрутные тесты подтверждают сохранение происхождения.
- [x] `npm run lint`, `npm run check` и `npm test` проходят.
- [x] Изменения оформлены одним коммитом.
