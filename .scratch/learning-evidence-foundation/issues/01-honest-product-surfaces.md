# 01 — Честные состояния незавершённых экранов

Status: done
Blocked by: —
Spec: .scratch/learning-evidence-foundation/spec.md#solution

## Что сделать

Оставить «Пробный ЕГЭ» видимым, но превратить его из фиктивного экзамена в честный экран «в разработке» с переходами только к уже работающим отдельным экзаменационным режимам. Скрыть «Достижения» из пользовательской навигации и удалить со старого экрана прогресса фиктивный график, прирост и официально выглядящие CEFR-ярлыки, установив честное состояние ожидания реальных данных.

## Границы

- Входит пользовательская навигация, экран пробника, достижения и legacy-блоки прогресса.
- Полный сквозной экзамен и движок достижений не входят.

## Definition of Done

- [x] «Пробник» остаётся доступным и явно помечен как разрабатываемый.
- [x] На экране нет фиктивного таймера, `14/40` и выдуманных этапов.
- [x] Доступны только переходы к реально работающим экзаменационным тренировкам.
- [x] «Достижения» недоступны из обычной навигации.
- [x] Фиктивный график, `+18` и статические A2/B1/B2 отсутствуют.
- [x] Целевые frontend/DOM-тесты проходят.
- [x] Один коммит на тикет.
