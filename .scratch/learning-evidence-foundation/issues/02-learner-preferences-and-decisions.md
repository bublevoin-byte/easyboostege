# 02 — Рабочие учебные настройки профиля

Status: done
Blocked by: 01 — Честные состояния незавершённых экранов
Spec: .scratch/learning-evidence-foundation/spec.md#implementation-decisions

## Что сделать

Заменить статические класс, цель и длительность занятия в профиле на owner-bound данные: класс и предпочтительная длительность сохраняются с офлайн-синхронизацией, а цель по баллам читается и редактируется через существующую цель индивидуального плана. Предпочтительная длительность становится начальным значением конструктора занятия. Зафиксировать будущие решения по VK ID и платёжному адаптеру в ADR.

## Границы

- Входят профиль, строгая валидация предпочтений, синхронизация, использование длительности и архитектурная запись решений.
- Реализация VK OAuth и Robokassa не входит.

## Definition of Done

- [x] Класс 8–11 и длительность 15–120 минут с шагом 5 сохраняются по аккаунту.
- [x] Офлайн-изменение синхронизируется после восстановления сети.
- [x] Профиль не показывает фиктивный класс или цель.
- [x] Цель по баллам берётся из adaptive goal и изменяется в едином редакторе.
