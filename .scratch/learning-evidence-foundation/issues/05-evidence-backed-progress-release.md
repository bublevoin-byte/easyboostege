## Что сделать

Собрать итоговую сводку прогресса из существующего owner-bound adaptive evidence profile: показать все шесть модулей, степень освоения, надёжность и объём данных либо честное пустое состояние. Проверить сквозной путь от обычного занятия до обновлённой сводки и подготовить первый этап к безопасному локальному выпуску.

## Границы

- Входит пользовательская сводка, доступность, сквозные тесты и документация первого этапа.
- Официальная сертификация CEFR/IELTS, деплой и включение feature flags не входят.

## Definition of Done

- [x] Сводка содержит vocabulary, grammar, reading, listening, writing и speaking.
- [x] Нет evidence — показано «недостаточно занятий», а не нулевой официальный уровень.
- [x] Preliminary и established состояния визуально и текстово различаются.
- [x] Освоение сопровождается уверенностью/объёмом доказательств.
- [x] Обычное занятие обновляет owner-bound профиль и затем сводку.
- [x] Офлайн-состояние не выдаётся за свежие серверные данные.
- [x] Реальный Chromium проверяет ключевой пользовательский путь.
- [x] Полный тестовый набор, lint/check и frontend build проходят.
- [x] Один коммит на тикет.
