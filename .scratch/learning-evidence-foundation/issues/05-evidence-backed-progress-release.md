# 05 — Прогресс из реальных учебных свидетельств

Spec: .scratch/learning-evidence-foundation/spec.md#solution

## Что сделать

Собрать итоговую сводку прогресса из существующего owner-bound adaptive evidence profile: показать все шесть модулей, степень освоения, надёжность и объём данных либо честное пустое состояние. Проверить сквозной путь от обычного занятия до обновлённой сводки и подготовить первый этап к безопасному локальному выпуску.

## Границы

- Входит пользовательская сводка, доступность, сквозные тесты и документация первого этапа.
- Официальная сертификация CEFR/IELTS, деплой и включение feature flags не входят.

## Definition of Done

- [ ] Сводка содержит vocabulary, grammar, reading, listening, writing и speaking.
- [ ] Нет evidence — показано «недостаточно занятий», а не нулевой официальный уровень.
- [ ] Preliminary и established состояния визуально и текстово различаются.
- [ ] Освоение сопровождается уверенностью/объёмом доказательств.
- [ ] Обычное занятие обновляет owner-bound профиль и затем сводку.
- [ ] Офлайн-состояние не выдаётся за свежие серверные данные.
- [ ] Реальный Chromium проверяет ключевой пользовательский путь.
- [ ] Полный тестовый набор, lint/check и frontend build проходят.
- [ ] Один коммит на тикет.
