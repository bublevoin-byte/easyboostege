# 04 — Статические записи и безопасный xAI TTS-конвейер

**What to build:** владелец может одной командой проверить все 60 сценариев, увидеть точное число символов и цену, а после отдельного подтверждения — возобновляемо создать immutable MP3; ученик слышит готовую запись, а при её отсутствии видит честно обозначенный fallback.

**Blocked by:** 03 — Интервью заданий 3–9 и полный пилот 60.

**Status:** done

- [x] Dry-run валидирует каталог, перечисляет недостающие записи и считает символы/стоимость без fetch и записи MP3.
- [x] Платный режим требует явный CLI-флаг и `XAI_API_KEY`; секрет не логируется и не сохраняется.
- [x] Генерация пропускает уже валидные файлы, проверяет MIME/размер/checksum и атомарно обновляет manifest.
- [x] Браузер предпочитает manifest-backed MP3 и корректно останавливает/последовательно проигрывает роли.
- [x] При отсутствии/ошибке MP3 включается явно обозначенная тренировочная синтезированная озвучка.
- [x] Fake-provider тесты, TTS/frontend тесты, lint/check и frontend build проходят без платных вызовов.
- [x] Один коммит закрывает только этот тикет.
