# 05 — Умная ротация, индивидуальный план и выпускной контур

**What to build:** приложение сначала показывает невстречавшиеся записи, затем возвращает слабые и давно не выполнявшиеся, честно учитывает помощь/раскрытый транскрипт и подтверждает полный пользовательский путь «каталог → запись → разбор → индивидуальный план».

**Blocked by:** 04 — Статические записи и безопасный xAI TTS-конвейер.

**Status:** ready-for-agent

- [ ] Owner-bound история хранит только безопасные метаданные попыток по id/revision.
- [ ] Выбор предпочитает unseen, не повторяет предыдущий id при наличии альтернативы и затем учитывает слабость/давность.
- [ ] Замедление, дополнительные прослушивания и повтор после раскрытого транскрипта отмечаются assisted/help и не завышают независимую диагностику.
- [ ] Каталог и доступные MP3 корректно участвуют в offline shell/cache без раскрытия ответов до проверки.
- [ ] Chromium E2E проходит по одному сценарию каждого формата и подтверждает adaptive evidence.
- [ ] Полный набор тестов, lint/check, frontend build и secret scan проходят.
- [ ] Выпускная проверка фиксирует, что платных вызовов, push и deploy не было до отдельного разрешения.
- [ ] Один коммит закрывает только этот тикет.
