# 01 — Экзаменационное сопоставление и контракт каталога

**What to build:** ученик получает 20 оригинальных комплектов сопоставления в формате шесть говорящих / семь утверждений, а приложение загружает их из единого строго проверяемого каталога и публикует реальный результат gist в индивидуальный план.

**Blocked by:** None — can start immediately.
