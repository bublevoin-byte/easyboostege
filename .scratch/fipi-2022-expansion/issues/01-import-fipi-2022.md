# Импортировать проверяемые работы ФИПИ 2022

Status: done

## Acceptance criteria

- `npm run quality:sources` знает специальные имена PDF 2022 года.
- Текст обоих документов извлечён локально и проверен.
- В золотые наборы добавлены только полные работы с опубликованной оценкой.
- Условия с изображений имеют визуально проверенное происхождение.
- Документация и ТЗ называют фактическое число добавленных работ.
- Все тесты проходят; результат зафиксирован одним локальным коммитом.
